### Data/raw_files/league_files

#### English Premier League Files
Files that look like "E0xxyy" are files that contain data on english premier league matches for the xxyy season so the 
2026/2027 season would be file E02627 

Files came from: https://football-data.co.uk/englandm.php

Here each individual file was downloaded and put into the data/raw_files/league_files/ folder
